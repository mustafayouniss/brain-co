# 🏛️ System Architecture Documentation

هذا المجلد يحتوي على الوثائق المعمارية التفصيلية لمشروع **Organizational Brain**:

- **Three Layer Model**: المعمارية ثلاثية الطبقات (العقل العام General Brain -> الذكاء المجالي Domain Intelligence -> ذكاء المؤسسة Organization Context).
- **Knowledge Lifecycle**: دورة حياة المعرفة وفصل الملاحظة عن المعرفة (Observation ≠ Knowledge).
- **Case Isolation Model**: نموذج العزل الصارم للقضايا ومنع تسرب البيانات بين القضايا لنفس الموكل (Client ≠ Case).
- **Autonomy Model**: نموذج التدرج في سلطة الذكاء الاصطناعي (Observe → Assist → Execute with Approval → Automate).
- **Multi-Store Persistence**: معمارية التخزين المتعدد (Relational + Vector + Graph + Data Lake).
