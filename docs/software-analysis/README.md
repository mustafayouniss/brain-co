# 🔍 Software Analysis & Modeling

يوثق هذا المجلد مخرجات مرحلة التحليل والنمذجة البرمجية (Step 3+):

- **Actors and Roles**: الممثلون البشريون (المحامي، مراجع المعرفة، الموكل، المدير، المسؤول) وممثلو النظام (General Brain, Legal AI Employee).
- **Use Case Catalog**: فهرس حالات الاستخدام لجميع الحلقات.
- **Context Diagram**: حدود النظام والجهات الفاعلة الخارجية (واتساب، CRM، بوابات الدفع، المحاكم).
- **Activity Diagrams**: مخططات سير الأنشطة لعمليات الرصد، التثبت، وحل التناقضات.
- **State Machines**: آلات الحالة للقضية (Case Lifecycle)، المعرفة (Knowledge Lifecycle)، والنزاعات (Conflicts).
- **Sequence Diagrams**: المخططات التتابعية للسيناريو الشامل (WhatsApp Ingestion → Assistance → Learning).
- **Domain Class Diagram**: مخطط أصناف النطاق وعلاقاتها.
