## Docker Integration & Latest-Code Deployment

### Context & Mission
Integrated teammate Yousef Hamada's Docker implementation (`fb032df7` from `origin/docker-setup` and `origin/main` PR #4) into the latest local `brain-co` codebase while preserving 100% of the latest application logic, database migrations (`f82a1b3c4d5e`), security hardening (CACS, WebSocket ticket hashes, boundary enforcement), and real-time streaming capabilities.

### Key Actions & Architecture
1. **Docker Compose (`docker-compose.yml`)**:
   - Standardized Compose project name to `name: brain-co`.
   - Re-attached to existing persistent database volume `brain-co_pgdata` on PostgreSQL 17 + pgvector.
   - Excluded `neo4j` (strictly prohibited by Constitution / AGENTS.md non-negotiable stack; Ring 1 uses PostgreSQL + pgvector).
   - Configured robust container healthchecks:
     - PostgreSQL: `pg_isready -U postgres -d orgbrain_legal`
     - Backend: Python `urllib.request` on `http://127.0.0.1:8000/health`
     - Frontend: Node.js `fetch` on `http://127.0.0.1:3000`
   - Port mappings:
     - PostgreSQL: `5433:5432`
     - FastAPI Backend: `8000:8000`
     - Next.js Frontend: `3000:3000`
     - Adminer: `8080:8080`

2. **Backend Container (`backend/Dockerfile`)**:
   - Base image: `python:3.12-slim`.
   - `PYTHONPATH=/app:/app/backend:/app/data-engineering:/app/ai:/app/brain:/app/brain/src`.
   - Implemented hybrid wheel cache (`wheels/`) allowing instant offline `pip install --no-index` while preserving clean fallback to PyPI for fresh checkouts.
   - Automated startup migration: `alembic upgrade head && uvicorn app.main:app --host 0.0.0.0 --port 8000`.

3. **Frontend Container (`frontend/Dockerfile`)**:
   - Base image: `node:22-alpine` (matching teammate's PR base).
   - Local context module and build artifact detection: utilizes pre-existing modules and build artifacts when present, with clean fallback to `npm ci --include=dev` and `npm run build` on fresh checkouts.
   - Fixed Turbopack hardcoded host root in `frontend/next.config.ts`.
   - Synchronized `next` to `16.4.0` in `frontend/package.json` to prevent lockfile synchronization mismatches during `npm ci`.

4. **Documentation**:
   - Authored `docs/DOCKER.md` covering architecture, one-command deployment, port mapping, environment variables, healthcheck verification, and troubleshooting.
   - Updated `.env.example` with sanitized Docker variables and placeholders (zero secrets).
