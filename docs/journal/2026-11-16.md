## 13:18 — Next.js Runtime Security Upgrade to 16.4.6 (Runtime Remediation)

### Context & Root Cause
An audit revealed that although `frontend/package.json` specified `16.4.6`, `node_modules/` on both host and inside the Docker container executed `16.4.0`.
Root causes:
1. `npm install --package-lock-only` had previously updated lockfile metadata without extracting tarballs to host `node_modules`.
2. `frontend/.dockerignore` lacked `node_modules` and `.next`, causing un-upgraded host artifacts to be sent in the build context.
3. `frontend/Dockerfile` checked `if [ ! -d "node_modules" ]`, skipping `npm ci` when host `node_modules` was present in the build context.

### Remediation Applied
1. Executed `npm install` inside `frontend/` on host, unpacking `next@16.4.6`, `eslint-config-next@16.4.6`, and verifying React 19.3.0 alignment.
2. Updated `frontend/.dockerignore` to explicitly ignore `node_modules` and `.next`.
3. Updated `frontend/Dockerfile` to copy `package.json` and `package-lock.json`, run `npm ci --include=dev`, copy remaining sources, and run `npm run build`.
4. Rebuilt frontend image with `docker compose build frontend --no-cache` and recreated container via `docker compose up -d --no-deps frontend`.

## 13:37 — React Error #300 Root Cause Fix & Verification

### Root Cause
`frontend/src/components/floating-chat-widget.tsx` contained an early return statement (`if (isLoginPage) return null;`) on line 79 before two `React.useEffect` hook declarations (lines 87 and 96).
Because `FloatingChatWidget` is mounted globally in `RootLayout`, navigating between `/` (where 15 hooks were executed) and `/login` (where only 13 hooks were executed) caused React 19 to detect that fewer hooks were rendered than during the previous render, throwing `Uncaught Error: Minified React error #300`. Conversely, navigating from `/login` to `/` threw React error #310 ("Rendered more hooks than expected").

### Fix Applied
Relocated the conditional return `if (isLoginPage) return null;` below all 15 hook declarations in `frontend/src/components/floating-chat-widget.tsx`. All hooks now execute unconditionally in the exact same sequence on every render.

## 16:58 — Phase 2 Visual Redesign & Art Direction Remediation

### Root Causes of Previous Visual Failure
1. **Monochromatic Uniform White Color**: The fragment shader passed a single hardcoded white uniform to all 18,000 particles without attribute-based spectral or structural differentiation.
2. **Missing Surface Normals & Flat Shading**: The geometry generator did not compute or pass surface normals $\vec{N}$. Without normals, directional diffuse lighting, ambient occlusion, and Fresnel edge highlights were impossible.
3. **Polar Coordinate Bunching**: Linear $\theta$ sampling bunched particles heavily at the crown ($\theta=0$) and base ($\theta=\pi$).
4. **Oversized Attenuation Scale**: Points inflated to 48px discs, saturating additive blending into a solid silhouette.

### Implementation Fixes Applied
1. **Anatomical Brain Sculpting (`particle-geometry.ts`)**:
   - Equal-area hemisphere sampling ($\theta = \arccos(1 - 2u)$) for uniform particle distribution.
   - Distinct anatomical lobes: anterior frontal pole, lateral temporal swell with Sylvian groove, posterior occipital taper, cerebellar hemispheres, and descending brainstem.
   - Controllable central longitudinal cerebral fissure with inward curving medial faces ($d_x = 0.10$).
   - Multi-harmonic gyri crests and sulcal valley depth modeling.
   - Mathematical outward surface normals computed and passed as `attribute vec3 aNormal`.
   - Structural region classification (`aRegion` 0..4) and unique phase offsets for action potentials.
2. **Directional & Fresnel Lighting Pipeline (`particle-vert.ts`)**:
   - View-space normal transformation: `normalView = normalize(normalMatrix * aNormal)`.
   - Directional Key Light (`vec3(0.6, 0.9, 1.2)`) illuminates frontal superior gyri in electric blue/cyan.
   - Directional Fill Light (`vec3(-0.7, -0.4, -0.6)`) softly illuminates sulci in deep violet.
   - Fresnel Rim Light (`pow(1.0 - N·V, 2.8)`) generates an electric cyan silhouette.
   - Traveling action potential wave propagates traveling neural flashes across synaptic nodes.
3. **Spectral Color System (`particle-frag.ts`)**:
   - Electric cyan (`#00f2ff`) and neural blue (`#0d73fa`) for primary activity.
   - Teal (`#05b3a6`) for structural tissue.
   - Deep violet (`#7a2ee0`) and midnight purple (`#2e0f6b`) for sulci and fissure crevices.
   - Restrained magenta (`#ff14a6`) for synaptic hotspot firing.
   - Dual-profile point sprite: brilliant pinpoint core with soft atmospheric glow.
4. **Cinematic Elevated Oblique Camera & Parallax (`brain-engine.ts`)**:
   - Elevated oblique view `(0.35, 0.55, 6.2)` looking at `(0, -0.05, 0)` reveals the longitudinal fissure and hemisphere depth.
   - Subtle organic breathing oscillation (slow yaw and pitch) provides realistic parallax.
