# Journal — 2026-10-27

## Goal
Implement the Ring 1 General Brain Peer-to-Peer Mesh Architecture, contracts, six engines (Perception, Observation, Context, Basic Memory, Basic Retrieval, Planning), database models, Alembic migration, and comprehensive test suite with strict context isolation.

## What was done
1. **Architecture Audit & Implementation Plan**:
   - Analyzed existing codebase (`backend/app`, `ai/`, `docs/`, `migrations/`).
   - Reused existing LLM provider abstraction (`ILLMProvider`, `LLMService`, `FakeLLMProvider`), SQLAlchemy Base, test fixtures (`test_engine`, `db_session`), and configuration.
   - Authored and approved implementation plan artifact `ring1_implementation_plan.md`.

2. **Typed Contracts & Mesh Infrastructure (`backend/app/ring1/contracts/` & `mesh/`)**:
   - Created `envelopes.py`: versioned `MeshRequest` and `MeshResponse`, `MessageType`, `ResultStatus`, `MeshConstraints` (`DelegationConstraints`), `MeshError`.
   - Created `capabilities.py`: constants for all Ring 1 capabilities, `ALL_CAPABILITIES` allowlist, `CapabilityRegistry` with lookup/registration.
   - Created `context_ref.py`: `ContextRef` with `ResolutionStatus`, scope constraints, and case boundary propagation.
   - Created `errors.py`: `EngineErrorCode` covering validation, authorization, execution, delegation, data, and planning failure modes.
   - Created `plan_models.py`: `Plan`, `PlanStep`, `PlanStatus`, `StepStatus`, `ReplanRequest`, `ReplanResponse`, `ReplanReasonCode`.
   - Created `mesh/router.py`: `MeshRouter` handling capability dispatch, validation against allowlist, timeout enforcement, and trace propagation.

3. **Database Models & Alembic Migration (`backend/app/ring1/models/` & `backend/migrations/`)**:
   - Created `ring1_observations` table model (`Observation`) with idempotency keys, JSONB payload/metadata, case_id/context_ref indexing.
   - Created `ring1_memory_records` table model (`MemoryRecord`) with case_id scoping and trace links.
   - Created Alembic migration `f19a0a1b2c3d_create_ring1_tables.py` linked to head `e819b932c01a`.

4. **Six Engine Implementations (`backend/app/ring1/engines/`)**:
   - `BaseEngine` (`base.py`): Intelligence Layer + Deterministic Core pattern, delegation support, safe error handling.
   - `PerceptionEngine` (`perception.py`): Deterministic JSON/text/system_event parsing with automatic format detection and LLM fallback.
   - `ObservationEngine` (`observation.py`): Event capture, duplicate detection via idempotency keys, follow-up policies.
   - `ContextEngine` (`context.py`): Context scope resolution, case_id boundary validation, ambiguity reporting.
   - `BasicMemoryEngine` (`memory.py`): Context-scoped persistence (DB and in-memory), idempotency, cross-case access prevention.
   - `BasicRetrievalEngine` (`retrieval.py`): Context-scoped search, case_id filtering, pagination, keyword and record_type matching.
   - `PlanningEngine` (`planning.py`): Multi-step plan creation, capability validation against `ALL_CAPABILITIES`, bounded replanning (`REPLAN_LIMIT_EXCEEDED`).

5. **ADR-008 & Documentation Updates**:
   - Authored `docs/adrs/ADR-008-planning-engine.md` documenting the Planning Engine as the approved 6th engine without altering the historical Constitution text.
   - Updated `docs/adrs/README.md`, `docs/backend/decisions.md` (D-016), `docs/backend/architecture.md`, `docs/backend/how-it-works.md`, and `docs/progress.md`.

6. **Comprehensive Automated Testing (`backend/tests/ring1/`)**:

   - Tested contracts, all 6 engines, mesh peer delegation, and cross-case data isolation (in-memory and PostgreSQL test container).

## What Went Wrong & How It Was Fixed
1. *Issue*: `ImportError: cannot import name 'DelegationConstraints' from 'app.ring1.contracts.envelopes'`
   *Fix*: Added `DelegationConstraints = MeshConstraints` alias in `envelopes.py`.
2. *Issue*: `AttributeError: type object 'EngineErrorCode' has no attribute 'INVALID_PAYLOAD'`
   *Fix*: Expanded `EngineErrorCode` enum in `errors.py` with standard codes (`INVALID_PAYLOAD`, `AUTHORIZATION_DENIED`, `CAPABILITY_NOT_FOUND`, etc.).
3. *Issue*: `TypeError: MeshRouter.__init__() got an unexpected keyword argument 'default_timeout_seconds'`
   *Fix*: Added `default_timeout_seconds: float = 30.0` parameter to `MeshRouter.__init__`.
4. *Issue*: In `BasicRetrievalEngine`, in-memory keyword matching only checked `payload` and `metadata`, missing matches where query matched `record_type`.
   *Fix*: Included `rec.record_type` in both in-memory and DB keyword search logic.
